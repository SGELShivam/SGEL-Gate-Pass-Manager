⚡ The 3 big steps

  1. One time: follow FIREBASE SETUP.html — create the free Firebase project and paste your keys into firebase-config.js.
  2. Every day: double-click START APP - double click.bat → the app opens at http://localhost:8007.
  3. First login: User ID admin + the password you made in the Firebase console → press the one-time "Create my Admin profile" button → add departments & users.
